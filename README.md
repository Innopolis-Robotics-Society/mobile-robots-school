# Школа мобильных роботов

Учебная программа Innopolis Robotics Society по мобильной робототехнике: от машинки на Arduino до автономной навигации на ROS 2. Здесь лежат пайбуки с инструкциями, прошивки, пакеты ROS 2, 3D-модели и схемы.

## Как устроена Школа

Школа идёт в три этапа. Работаем в смешанных командах: в каждой есть участники с опытом и новички.

| Этап | Платформа | Что делаем | Переход дальше |
| --- | --- | --- | --- |
| 1. Робот на Arduino | Iskra Uno, Motor Shield, датчики линии, захват | Собираем робота, разбираемся с моторами, энкодерами и датчиками, учим его ездить по линии туда-обратно | Робот проходит трассу, у команды есть видео и README |
| 2. Машинки на micro-ROS | ESP32 + Rpi 5 + ROS 2 | Переносим управление в ROS 2: топики, одометрия, телеуправление | Зачёт по заданию этапа |
| 3. AgileX Scout Mini, MAPF или проекты лаборатории | Scout Mini, ROS 2 Jazzy, Nav2 | SLAM и автономная навигация или работа в исследовательских проектах IRoS | — |

## С чего начать

1. Прочитайте [правила безопасности](docs/safety.md).
2. Установите [Arduino IDE](https://www.arduino.cc/en/software) и заведите аккаунт на GitHub.
3. Откройте [пайбук блока 1](playbooks/01-arduino-line/README.md) и пройдите раздел «Первое включение» по шагам.
4. Создайте репозиторий команды и сдавайте в него результаты каждого шага.

Вопросы задавайте в общем чате Школы.

```
├── docs/                    программа, безопасность
```

## Прошивки блока 1

Скетчи в [`firmware/arduino`](firmware/arduino) идут в порядке пайбука. Каждый скетч самодостаточен: карта пинов прописана в начале файла и одинакова для всех команд.

| Скетч | Что проверяет |
| --- | --- |
| `01_motor_test` | Направление и скорость моторов |
| `02_encoders` | Счёт тиков энкодеров |
| `03_line_calibration` | Калибровка датчиков линии |
| `04_servo_calibration` | Углы подъёма и губок захвата |
| `05_distance_sensors` | Sharp GP2Y0A21 и HC-SR04 |
| `06_line_follower_template` | Заготовка для езды по линии |

Плата в Arduino IDE — **Arduino Uno** (Iskra Uno с ней совместима).

## Клонирование

3D-модели, DXF, PDF и фото хранятся в Git LFS. Установите LFS до клонирования, иначе вместо файлов будут текстовые ссылки:

```bash
git lfs install
git clone git@github.com:Innopolis-Robotics-Society/mobile-robots-school.git
```

## Как сдавать результаты

Каждая команда ведёт свой репозиторий. В нём должны быть:

- код каждого шага;
- видео или график, подтверждающие результат шага;
- README команды: состав, схема подключения, подобранные коэффициенты и углы.

Исправления в пайбуках и прошивках этого репозитория присылайте через pull request.
