# Блок 1. Робот на Arduino: езда по линии

За этот блок команда собирает робота, разбирается, как работает каждый его компонент, и учит его ездить по линии туда-обратно. Здесь — введение: что за робот, к чему идём и в каком порядке проходить пайбуки. Документация по компонентам и задания — в пайбуках ниже.

## Цель блока

В конце блока робот:

- едет по линии, не сходя с неё;
- в конце линии разворачивается на 180° и едет обратно;
- едет по линии и взаимодействует с предметами через захват

Команда сдаёт видео заезда и README в своём репозитории: схему подключения, подобранные коэффициенты и углы. Кто сдал — переходит на блок 2, машинки на micro-ROS.

Чтобы дойти до этого, придётся разобраться, как устроены моторы и энкодеры, как датчик видит линию и как превратить показания датчиков в команды моторам так, чтобы робот не вилял.

## Робот

Двухъярусная платформа с дифференциальным приводом: два ведущих колеса по бокам и пассивная опора сзади. Руля нет — робот поворачивает, крутя колёса с разной скоростью.

| Что | Из чего |
| --- | --- |
| Контроллер | Iskra Uno (аналог Arduino Uno) с Troyka Shield для подключения датчиков |
| Моторы | 2 мотор-редуктора 12 В с энкодерами, колёса 72 мм |
| Драйвер моторов | Amperka Motor Shield Plus |
| Датчики | 2 аналоговых датчика линии, ИК-дальномер Sharp, ультразвуковой HC-SR04 |
| Захват | Подъём на сервоприводе MG996R, губки на SG90 |
| Питание | 3 аккумулятора 18650 (11,1 В), понижающий DC-DC на 5 В для серв |

У робота две ветки питания. Моторы и контроллер питаются от батареи через Motor Shield, сервы — через DC-DC. Контроллер только читает датчики и отдаёт команды.
